# canboat PGN Reference Definitions (v8.1.0)

Resmi canboat PGN tanımları — mevcut `n2k_canboat.dbc` (canboat-NMEA2000-curated,
620 mesaj / 4.105 sinyal) üst kümesidir ve PGN validasyonunda referans olarak
kullanılır.

- `canboat.json` (2.6 MB) — makine tarafından okunabilir PGN veritabanı (JSON)
- `canboat.xml` (3.2 MB) — insan tarafından okunabilir PGN veritabanı (XML)
- `canboat.dbc` (512 KB) — canboat'ın ürettiği DBC çıktısı (29-bit ID)
- `LICENSE` — Apache-2.0

değişikliklerini izleyin.
